# 03. Global System Wholeness & End-to-End Cohesion (全盘全局协同)

> 🔒 Dedicated Rule for Antigravity / Gemini Workspace Assistant in Digital Sanctuary (纯净领域).

---

## 1. Zero Broken Loops (严禁单点孤立修补)
- 任何涉及核心实体（画作、相册、画师、标签、搜索、主题）的改动，必须确保全流程闭环联动打通，杜绝“毛坯体感”与逻辑死胡同。

---

## 2. Core Entity Interaction Matrix

1. **画廊全景 (Flat Gallery)**:
   - 画作卡片悬浮、快捷加入相册下拉、多选批量操作胶囊条、Toast 提示与快捷撤销 (Undo)。
2. **相册画集 (Albums)**:
   - 精装封面对开、卷首题记、篇目目录索引 (TOC) 抽屉、双模式网格、相册内画作挑选浮窗、4 种动效无缝切换。
3. **画师馆藏 (Author Detail)**:
   - 画师专属页作品流、一键批量加入相册、直接调起全屏查看器。
4. **影院级全景查看器 (Cinema Lightbox)**:
   - 任何入口（画廊、相册、画师、顶部横幅）打开均应完整无裁切展示、支持滚轮缩放、拖拽平移、键盘全快捷键与多页胶片轨道。
5. **宽裕操作热区 (Hit Targets)**:
   - 交互按钮、罗盘旋钮、悬浮胶囊必须具有宽裕的命中范围（至少 36px~44px），防止边缘脱靶。
