## 清理结论

- 当前没有可安全删除的 ADR。
- 0001–0005、0007 即使实现已完成，也仍是当前代码的架构和安全依据。
- 0006 不是废弃决策，而是后续语义搜索实施必须遵守的边界；功能仍在 `docs/plans/ACTIVE_ROADMAP.md` 中排队。
- 如果未来决策发生变化，应新增 ADR，或在原 ADR 中明确标记 `Superseded by ADR NNNN`，不要静默删除历史记录。

## 维护规则

1. 新的不可逆架构选择先写 ADR，再进入施工计划。
2. 实现完成只更新“实现状态”，不删除 ADR。
3. 被替代的决策保留原文并标记替代关系；只有确认没有引用、没有安全边界和没有追溯价值时才归档。
4. 施工状态、验收证据和未完成事项分别维护在 `docs/plans/`、`docs/reviews/` 和 `docs/known-issues/`，不要堆回 ADR。
