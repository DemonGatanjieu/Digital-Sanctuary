# ADR 0004：视觉进程边界

- 状态：已接受（已接入首个真实模型）
- 日期：2026-08-10

## 决策

视觉能力通过版本化 JSON Lines 子进程协议暴露。视觉进程只接收图片路径并返回标签、置信度、引擎版本和耗时，不读取登录态、不写数据库，也不决定最终过滤动作。

项目使用独立的 Python 3.14 虚拟环境运行 WD SwinV2 Tagger v3 与 ONNX Runtime 1.28.0。桌面端优先启动该 Python 服务；开发环境缺少模型或虚拟环境时，回退到 TypeScript 的 `filename-probe`，并在界面明确显示当前引擎。

视觉服务只返回 category 0 的一般元素标签及置信度，主动丢弃 rating 标签。领域层使用用户黑名单决定隐藏，不把正常 R18 视为风险。模型必须经过二次元评测集验证；未来替换或补充专用模型时保持上层协议不变。
