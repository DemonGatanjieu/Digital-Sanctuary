# ADR 0002：未知图片的默认策略

- 状态：已接受
- 日期：2026-08-10（2026-08-11 补充信任边界）

## 决策

远程探索页中的图片在审查完成前保持遮挡。视觉引擎错误、超时、协议不兼容或站点适配器无法识别时同样保持遮挡，不允许静默放行。

从 Pixiv 主动保存或批量下载的作品属于用户已经明确选择的可信输入：直接清晰展示，清除旧 AI 结果，不因下载自动运行模型。未来若用户显式启动“模型整理”，失败只影响该次整理结果，不得把可信作品自动改为模糊或隐藏。

手动导入既有本地文件的当前实现仍会运行一次模型；模型错误时默认模糊并明确显示状态。若以后统一为显式整理，应另写 ADR 修改此行为，不能静默改变远程探索的失败闭合策略。
