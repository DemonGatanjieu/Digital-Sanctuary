# ADR 0003：首版图库所有权

- 状态：已接受并扩展（首版闭环）
- 日期：2026-08-10（2026-08-11 扩展）

## 决策

用户主动选择的既有本地图片仍只建立索引，不移动、不改名、不删除原文件。SQLite 保存路径、审查结果和分类关系。

从探索页主动保存的 Pixiv 作品由应用托管，目录固定为用户“图片/Digital Sanctuary/Pixiv/作品 ID”。每一页先写入同目录临时文件，再原子改名为 `作品ID_p页码.扩展名`；已存在的目标路径跳过网络下载，但会补齐本地画廊索引和来源元数据。

主动保存的单作品与收藏批量下载采用相同信任语义：保存 `allow` 决策并清除旧 AI assessment，不自动运行视觉模型。SQLite 同时保存作者 ID、作者名、作品标题、作品 ID 和页码，用于“作者 → 作品 → 多页”浏览。该元数据是本地索引，不改变磁盘目录所有权；应用当前不提供删除源文件操作。
