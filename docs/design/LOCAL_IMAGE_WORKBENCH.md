# 找图与整理工作台

- 状态：2026-10-09 已整合为来源、一个需求输入框和结果操作；背景与整理验收见[本轮记录](../reviews/2026-10-09-backgrounds-and-simple-organizing.md)
- 目的：把文件夹筛选、图库整理与结果取用收成一条任务流程，保持一级导航简洁

## 一个工作台，两种来源

现有图库中的整理页面逐步承接“找图与整理”，首页任务卡直接进入。来源切换为“我的图库 / 本地文件夹”；共用查找条件、结果选择和结果操作，不新增独立的导出中心、文件夹中心或自然语言中心。

流程：**选来源与范围 → 说出需求或留空排查 → 选中结果 → 就地处理**。

进入图库范围会自动读取图片预览，不运行模型；文件夹由原生选择器授权后预览。日常界面只有一个“想找什么”输入框和一个主按钮，不要求先选“缓存 / 元素 / 描述”等工作模式，也无需手动载入图库。相册建议与持久任务记录从次要入口展开，图库多选“推荐相册分类”及任务中心仍能直达。原先重复的缓存排查/预设面板收进这条流程；默认会分析当前范围尚未缓存的图片，不能把未分析当成无命中。

“选择文件夹”仅授权预览与显式分析，不自动导入。用户可以临时从一个文件夹挑图，不必先把整批资源写入图库。图库导入继续保留原文件，导出默认复制。界面明确当前范围、是否包括子文件夹、扫描/分析进度、未分析与分析失败数量；分页、取消和有界选择贯穿流程，达到扫描上限不能静默截断。

## 条件与模型

- 输入描述自动按画面检索；留空且没有附加元素时，主按钮为“按探索规则排查”，共用探索规则。只有附加元素时，按明确元素筛选。用户不必了解模式或模型分工。
- “附加筛选条件”折叠提供“需要 / 排除”元素，沿用 WD 标签结果；当前附加条件仍可见，英文标签放入更深的详情。界面不直接暴露阈值调参。分析失败或缺少结果不能算成“没有这个元素”。
- 按画面描述找图：输入场景、构图、氛围等自然语言，以 EmbeddingGemma 2 图文相似度排序。默认以与图库搜索共用的 0.65 启发式门槛收起较低相关性的图片，“全部图片”可展开同次结果，不重复推理。相似度不是识别正确率，也不保证精确否定。
- 两者可以组合。明确元素条件由可查看的选择项表达，不能把自然语言相似度当成“必须包含 / 排除”的严格证明。第一阶段不额外依赖大型聊天模型。
- 文件夹分析必须由主进程持有原生选择授权和文件清单，图片预览使用有界、窗口绑定的临时标识；不开放任意本地路径协议。模型任务遵守资源排队、取消与释放边界，不能和探索模型争抢显存。

## 结果就地使用

结果操作区提供“复制到文件夹”“加入相册 / 导入所选图片”；单张图片提供复制图片及打开所在位置。用户应看清当前操作针对单页还是整件多页作品。复制导出需要保持原图、处理同名冲突、提供部分失败与失败重试，不覆盖目标已有文件。图库选中结果可展开“移出所选作品”，预览后再确认；即使只选一页，也按整件作品处理全部页，托管文件进回收站，外部引用仅移除索引。范围变化立即收起旧结果与操作，重新提交后按新范围查找。

用户本轮明确：**改名只改变图库显示名称**。作品信息中提供“修改图库名称”，多页作品共用名称；原文件名、路径、来源标题、资产身份、分析记录及相册归属保留，搜索和所有图库展示入口使用同一名称。当前导出保留原始文件名，同名另存；使用图库名称作为导出文件名尚未实现。

## 实施顺序与状态

1. 图库命名和探索切换问题：本批实现与验收见 [`本批记录`](../reviews/2026-10-08-gallery-names-and-explore-transitions.md)。
2. 结果取用：已实现批量复制所选原图、单图复制与定位；整件作品导出与所选页操作有明确区分。
3. 本地文件夹来源：已实现默认探索规则、明确元素筛选、预览后选择导入或导出，复用既有导入确认。
4. 自然语言找图：已接入开发工作区准备好的 EmbeddingGemma 2 CPU 环境与版本化内容索引；图库和文件夹共用条件、结果及操作。没有独立聊天模型依赖。

本批上限为 1,000 张图片 / 20,000 个目录项，每次显示 60 张、选择最多 500 张。扫描未完成、分析失败与未分析分别提示，离页任务继续并可从任务中心返回；临时授权闲置 30 分钟过期，不跨重启恢复。相似度不承担严格否定，明确元素判断需要 WD 成功结果。剪贴板为可能缩小的栅格副本，原图复制保留原字节。

模型中心安装与发布包集成仍待后续；当前 0.1.2 安装器不包含本批能力或语义环境。本批范围和证据见[工作台验收](../reviews/2026-10-08-image-workbench.md)。设计依据为[产品与交互指导原则](./PRODUCT_PRINCIPLES.md)，运行边界以 [`ARCHITECTURE.md`](../../ARCHITECTURE.md) 为准。
