# 找图与整理工作台

- 状态：用户于 2026-10-08 同意的产品方向；以下阶段按各批实际验收推进
- 目的：把文件夹筛选、图库整理与结果取用收成一条任务流程，保持一级导航简洁

## 一个工作台，两种来源

现有图库中的整理页面逐步承接“找图与整理”，首页任务卡直接进入。来源切换为“我的图库 / 本地文件夹”；共用查找条件、结果选择和结果操作，不新增独立的导出中心、文件夹中心或自然语言中心。

流程：**选来源 → 找出需要的图片 → 选中 → 复制导出或收进图库**。

“选择文件夹”仅授权预览与显式分析，不自动导入。用户可以临时从一个文件夹挑图，不必先把整批资源写入图库。图库导入继续保留原文件，导出默认复制。界面明确当前范围、是否包括子文件夹、扫描/分析进度、未分析与分析失败数量；分页、取消和有界选择贯穿流程，达到扫描上限不能静默截断。

## 条件与模型

- 按明确元素找图：提供“需要有 / 不要有”，沿用 WD 标签结果；复杂阈值按需展开。排查不需要的元素时默认复用探索规则。分析失败或缺少结果不能算成“没有这个元素”。
- 按画面描述找图：输入场景、构图、氛围等自然语言，以 EmbeddingGemma 2 图文相似度排序。相似度不是识别正确率，也不保证精确否定。
- 两者可以组合。明确元素条件由可查看的选择项表达，不能把自然语言相似度当成“必须包含 / 排除”的严格证明。第一阶段不额外依赖大型聊天模型。
- 文件夹分析必须由主进程持有原生选择授权和文件清单，图片预览使用有界、窗口绑定的临时标识；不开放任意本地路径协议。模型任务遵守资源排队、取消与释放边界，不能和探索模型争抢显存。

## 结果就地使用

结果操作区提供“复制到文件夹”“加入相册 / 导入所选图片”；单张图片提供复制图片及打开所在位置。用户应看清当前操作针对单页还是整件多页作品。复制导出需要保持原图、处理同名冲突、提供部分失败与失败重试，不覆盖目标已有文件。

用户本轮明确：**改名只改变图库显示名称**。作品信息中提供“修改图库名称”，多页作品共用名称；原文件名、路径、来源标题、资产身份、分析记录及相册归属保留，搜索和所有图库展示入口使用同一名称。导出是否使用图库名称，留在导出流程中明确选择，不能通过改名隐式修改磁盘文件。
