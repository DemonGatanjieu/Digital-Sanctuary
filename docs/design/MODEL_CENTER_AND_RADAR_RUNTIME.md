# 模型中心与视觉雷达运行设计

- 状态：第二阶段已实现，并完成本地 Qwen 真实图片推理验收
- 更新日期：2026-08-30

## 用户能得到什么

纯净领域安装后仍然立即可用：安装包内的 WD SwinV2 负责探索元素识别。模型中心提供可选升级，但不会在用户不知情时塞入几个 GB 的下载。

用户可以：

1. 查看每个模型负责什么、体积、许可、建议内存/显存和官方来源；
2. 一键安装、暂停后续传、切换和删除非内置模型；
3. 在画廊大图里直接生成完全离线的技术雷达画像；
4. 按需下载本地 Qwen 或 Gemma 评论模型；不填写 API Key 也能主动生成标准六维评价；
5. 选择“AI 自选六维”，让视觉模型根据当前作品自行命名六个观察轴；也可继续使用已配置的外部视觉服务。

## 文件与安全规则

- Windows 默认模型目录：`%LOCALAPPDATA%/digital-sanctuary/models/`。
- 下载只接受代码内清单声明的 HTTPS 地址；Renderer 不能提交 URL 或文件路径。
- Gemma 权重与视觉投影 URL 锁定 Hugging Face 完整 40 位 revision，不跟随 `main` 漂移。Hugging Face 仓库改名通常保留重定向，但这只作为可用性便利，不能替代本地大小与 SHA256 校验。
- 每个文件必须同时匹配声明大小和 SHA256；验证通过后才从 `.downloads/<modelId>/` 移入正式目录。
- 固定运行时 ZIP 仅接受受控清单条目；解压拒绝绝对路径、目录穿越、加密、未知压缩方式、超量条目和解压体积炸弹。
- 中断下载留下 `.part`，下一次安装用 HTTP Range 续传；服务端不支持续传时从头覆盖。
- 内置模型不能删除，当前模型必须先切走才能删除。
- 保存的模型缺失或损坏时，启动自动回到内置 WD SwinV2。
- 本地评论服务只监听随机的 `127.0.0.1` 端口并使用进程内随机 API Key；Renderer 不接触模型路径、端口或密钥。

## 模型切换语义

元素模型不是只改一个下拉框。切换时需要：

1. 暂停并清空远程图片的进程内待审查状态；
2. 使用新目录、模型 ID 和哈希重启 Python 视觉子进程；
3. 通过模型身份握手和真实启动探针；
4. 成功后才保存选择并使旧引擎分析缓存失效；
5. 失败则尝试恢复旧模型，探索按全局模型故障处理，绝不生成逐图“已拦截”。

本地评论模型走独立的 llama.cpp 子进程，不与探索 WD Tagger 共用队列或故障状态。启用时先完成 `/health` 自检，推理严格串行；单次超过 90 秒会中止并重启运行边界，闲置 2 分钟自动退出以释放内存与显存，也可以在模型中心点击“停用并释放”。评论模型损坏、超时或回答不合规，只会让本次雷达评价失败，绝不会遮罩探索图片。

## 雷达结果语义

- 本地技术画像是统计描述，不是审美分数；它离线运行并以作品封面资产版本作为缓存边界。
- AI 六维评价是主观评论，结果必须显示来源模型。不同 provider/model 的分数不能默认混在同一套排序里。
- “标准六维”轴固定，适合查看同一模型下多张作品的相对差异；“AI 自选六维”由模型按单张作品命名轴，更像一份个性化画评，不适合跨作品按分数硬排序。
- 画评提示词使用 50/70/85/95 分锚点，要求理由指向可定位的画面证据并允许指出限制；不得把所有维度礼貌性堆在 90 分以上。Gemma 4 使用官方建议的 image-first 内容顺序及采样参数，Qwen 保留低温结构化输出配置。
- 自选结果必须恰好六项，维度键和中文标签不能重复，必须给出可见证据；模板占位词、全零分或无法解析的 JSON 会被拒绝，不保存成一张看似成功的雷达图。
- 缓存键包含资产版本、套件版本、预处理指纹、provider 和 model；失败结果不做长期缓存。
- 雷达结果与探索个人偏好、黑名单和本地画廊可信显示彻底分离。

## 已完成的运行时门槛

本地 Qwen 评论运行时采用单独、可替换的本机服务，没有塞进 WD Tagger 子进程。本阶段已经落实：

1. llama.cpp / 兼容运行时的固定版本与 Windows GPU/CPU 降级路径；
2. 模型和视觉投影文件的官方大小、SHA256 与许可记录；
3. 固定 JSON Schema 输出、超时/崩溃恢复和无效回答拒绝；
4. 模型中心明确展示下载体积和建议 RAM/VRAM；默认安装包不包含也不静默下载评论模型；
5. 只允许单作品显式运行，严格串行，绝不在滚动或启动时后台批量评分；
6. 安装包升级不覆盖用户下载模型、画廊和评价结果。

2026-08-30 使用官方 Qwen3-VL 2B Instruct Q4_K_M、官方视觉投影和官方 llama.cpp b10516 Windows Vulkan 包完成真实图片烟雾测试：运行时成功启动，返回六个不同的中文维度、非全零分数、逐项理由和总评；同一套严格校验也用于正式应用。

## 后续扩展边界

- 新增更强的本地评论模型时继续复用 `art_critic` 能力、GGUF + mmproj 清单和同一结构化结果协议，界面不为每个模型另造按钮。Gemma 4 E2B/E4B 已按此边界接入；在完成本机真图对照前不宣称其必然优于其他模型。
- 可以增加显式“取消本次评论”和更细的 CPU/GPU 资源预估，但不能把评论改成滚动时的后台批处理。
- 轻量美感分类头只有在其依赖的特征提取路径、训练标签含义和跨模型兼容性经过测试后才允许启用；7.9 MB 的分类头不等于完整可运行模型。
