# 图库快用审核

- 日期：2026-10-08
- 回滚基线：`4c98fbc`
- 范围：卡片直接改名、图片快捷复制/拖出、自定义图库横幅、保存方式筛选；后续网站与检索对话仅记录方案。

## 交付

1. 卡片标题旁常驻改名，复用原有作品名称存储和校验；只改显示名称。多页作品复制/拖出明确为封面，整件原图复制入口继续保留。
2. 原生拖放沿用可信目标解析，不接受 Renderer 文件路径。主窗口主 frame 之外的调用被拒绝；每次重新定位文件，缺失、过期、非普通文件和原生调用失败显示中文反馈。当前 Windows Electron 43.3.0 原生实现仅 COPY/LINK，保留原件。
3. 横幅使用原生选择器、有界读取和图片头尺寸检查，生成至多 1,600×900 JPEG，独立保存 SQLite 偏好。原文件删除后横幅仍可用，取消/失败保留旧值，恢复自动精选可用；省电或关闭氛围图时保留设置按钮。
4. managed/external 条件贯穿主进程输入校验、SQL 计数/分页、前端查询代次和保存筛选，卡片同时标明归属。与搜索、相册及喜欢条件组合；旧请求不能混入新归属结果。导入默认仍是外部引用，没有隐式复制或自动转换。
5. 工具栏窄窗换行，卡片作者与保存方式合为一行；改名和取用按钮至少 36 CSS px。修正图库工具栏、卡片及分段控件的固定白底，使用主题 token；横幅文字使用固定深色遮罩保持可读。

- `npm.cmd run verify`：474 项 TypeScript / 95 文件、9 项 Python、完整类型检查和生产构建通过。
- 聚焦测试覆盖可信文件拖放、不透明目标、原文件保留、错误/取消、横幅独立持久数据与大小限制、并发选择/重置、主 frame 归属、SQL 条件组合、计数/分页、保存筛选和迟到分页失效。
- `npm.cmd run smoke:gallery-actions`：10 组隔离真实 Electron 检查通过。使用生产 Renderer、preload、IPC、数据库、剪贴板和 JPEG 编码，仅替换原生选择器回答与最终 `startDrag` 接收端。覆盖卡片改名、中文输入法、真实剪贴板、拖放目标、筛选恢复、横幅原件删除/取消/返航、900/1280 布局、卡片按钮范围、省电重载和原件缺失错误。
- 暗色主题保存方式、搜索与排序控件文字对比度均约 16.95:1。截图和报告位于 `.tmp/gallery-actions-smoke/`，其中 `card-quick-actions-900.png` 展示卡片操作；该目录为本地生成证据，不提交。
- `node scripts/smoke-viewer.mjs`：20 组检查通过，包含两种大图入口、信息层、改名失败重试、输入焦点、缩放/平移、重启续读和保存筛选。
- `node scripts/smoke-navigation.mjs`：59 组检查通过，覆盖跨页导航、原生探索遮挡、宽窄窗、缩放、迟到状态、导入与任务返航。

## 实际边界与后续

- 系统拖放接收端使用替身，不能声称资源管理器或任意第三方软件的真实接收已经验收；需要用户按住手柄实际拖出确认。接收软件须支持文件拖放。
- 横幅是本地装饰图，GIF 使用静态画面；不保留外部路径，也不会触发模型识别。
- 本地导入的“复制到图库保存”选项和外部原图重新定位尚未实现；当前筛选只反映已有归属。
- 普通图库搜索仍查名称/作者/ID；中文画面找图仍在找图与整理。EmbeddingGemma 不生成聊天回答，现有创作页支持单张参考图对话，检索结果自动携图、多图对话与通用网站收图尚未接入。
- 后续流程见[设计记录](../design/LIBRARY_QUICK_USE_AND_DISCOVERY.md)。当前 0.1.2 安装器未重打。
