## 用户路径

探索 → 浏览保护 → 中文规则开关 / 更换识别模型，无需离开 Pixiv 页面找两个设置分类。普通开关不预先冒充成功；持久化失败保留原状态并可重试。精确阈值需要主动应用，原始标签、自定义组、个人学习权重和统计藏在按需展开项。规则更新只应用于后续审查；保护就绪时可主动按新规则重查本页。模型目录可在当前面板安装额外识别模型，日常选择只列已安装且已接入的识别引擎，不混入创作模型。

设置保留存储、外观、模型管理、高级连接四类。字体、头像、拨盘、备份迁移、云端服务与 ComfyUI 表单初次展开才挂载，已访问内容关闭或换分类时保留草稿。统一模型文件管理仍在设置中；未接入的整体观感、相似搜索不再占日常菜单。下载体积可见，精确资源需求、版本、许可和来源默认收起。

相册/画师的四种浏览模式仍全部可达；两组四种画册偏好移入展示选项，持久化和翻页状态机保留。两套大图工具统一收进分析与创作，选择后关闭菜单，菜单键盘操作不翻动背景作品。

## 遮挡与状态

- 宽窗原生网页与保护面板采用独立布局，面板不浮在原生网页上。CSS 宽度不超过 1100px 时保护面板占据内容区并隐藏网页，关闭后恢复原生视图和焦点；上层弹窗继续隐藏网页并拥有输入。
- 主进程使用 IPC 调用方真实 `getZoomFactor()` 将 CSS 坐标换算为 Electron DIP。屏幕 DPI 不重复乘入。真实窗口测试发现 150% 界面缩放被旧 body 最小宽度挤出 47px，去掉该 CSS 下限后复验。
- App 持有保护写入的 busy 状态，面板关闭或跨页期间写入继续完成；重开仍锁定编辑直到结果返回。完整列表回复串行处理，读取代次使旧加载结果失效。模型操作也串行，防止多个按钮同时切换；旧面板中的任务完成后，新面板及设置模型管理重新读取最终选择。
- 账户帮助放进账号操作区，展开会占用正常布局，避免在原生网页上做不可靠的 CSS 浮层。
