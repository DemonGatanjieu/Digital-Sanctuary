# 导入归属、网站收图与多图讨论验收

日期：2026-10-08。回滚基线：`949332811e86fbda4f981b01f8882960c5f1e244`。范围是用户确认接入的完整素材流程，不新增一级导航。

## 已完成

- 导入就地选择复制保存（默认）或原位置引用，原文件保留。副本排他复制到当前根目录 Imports，复核源/副本 SHA256，再与相册一起事务入库；失败/取消清理未入库副本。重复复用区分 managed/external，不把旧外部记录改成副本。
- 外部作品信息提供重新定位。原生选文件，已知指纹必须一致；资产 ID、显示名称和相册保留。早期无指纹记录允许重定位，但清除无法校验的旧标签、画评与缩略图。更改保存位置只迁移 managed，外部引用即使位于旧根目录也保留原位置。
- 探索地址栏输入网址或关键词图片搜索，最多 12 个常用网站快捷入口。普通站点独立沙箱、无 preload / 本地 API，明确未适配元素拦截；Pixiv 使用原保护视图，不从普通视图绕过保护门。
- 普通网页图片上右键加入图库。公开地址/DNS、逐次重定向、图片 MIME/签名、30 秒/32 MB 有界读取，排他保存到 Web；原图、归属、标题、页面与图片来源事务提交。复用已有 managed 图片不覆盖原名称/来源。
- 找图结果选中 1–4 页直接打开创作草稿；文件夹先确认导入，再讨论本窗口批次成功入库的图片。创作页支持追加、替换第一张与逐张移除，发送前可改写提问；失败不会把临时文件夹授权保存为永久来源。
- 本地视觉模型实际接收有序多张图片；逐回答来源和 Markdown 包含本轮参考作品/页。单图 32 MB / 3,200 万像素、总准备图片 32 MB；多图长边 560，按需扩至 8192 上下文。单图和画评保持 4096 初始上下文，仍共用串行队列与闲置释放。

## 实际边界

- GUI 烟测控制网站 HTTP 响应、原生选择器/菜单边界，应用、数据库、文件复制和沙箱视图为真实生产代码。模型请求测试使用本地 HTTP 运行时替身，验证实际多张图的传输和保存，**本轮没有真实 Gemma/Qwen 多图质量或显存实测**。应用安装视觉模型后使用真实运行时；未安装时显示就地安装入口，不把 EmbeddingGemma 当成聊天模型。
- 普通站点只有浏览和用户主动收图，暂不提供通用元素保护，也不自动抓取整页图片。保存的是网页实际提供的图片字节；blob/canvas、SVG、专门防盗链、第三方 OAuth 和隐藏高清源需要后续适配或先下载再导入。
- 文件夹讨论需先明确导入；批次过期、取消和部分失败均不扩权。外部引用仍可能受用户移动/删除原文件影响，重新定位不会自动遍历磁盘。
- 本轮未重新打包现有 0.1.2 安装器，也未自动下载新创作模型。语义模型中心安装及发布运行环境集成仍单独待办。
