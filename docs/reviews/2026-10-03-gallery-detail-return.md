## 用户可见变化

从设置、探索或创作返回，相册与画师详情保留浏览模式、已完成书页和列表位置。网格、篇目列表、画师套图各自记住位置；TOC 抽屉不会自动打开，手动打开后恢复原来的目录位置。目录和详情的位置分开保存，导航前同步捕获，浏览器尚未派发最后一次滚动事件也能返回原处。

删除当前页后优先回到存活邻页，再回退有效序号；删除整个范围则回目录并清除快照。同一范围 ID 重新出现会建立新会话，旧请求也不能把另一个范围的模式和位置覆盖回来。翻页中途离开只恢复最后完成的展对，大图、选图弹窗和动画不恢复。

小窗口相册导航改为标题/操作与模式两行；共用画册工具栏将篇目索引、翻页效果、装裱风格分为三行。两组四种选项全部保留，中文标签保持横排，最小窗口的这些按钮至少 36px。短窗口相册画册可在舞台内上下滚动，底部提示保留；舞台滚动和书页位置分别恢复。

## 状态与性能边界

- `GalleryDetailSessionCache` 按真实相册/画师 ID 保存最多 20 条 LRU 会话，未知画师 NULL 与字符串 ID 不碰撞；读写复制并规范化，只保存合法子模式、有界 ID 与数值。
- `PageAnchor` 先匹配真实资产，再回退 legacy 页；保存当前、前后邻页及有效序号，插入、重排、删除后重新映射。画册使用已完成展对的锚点，不保存转场目标。
- `useDetailScroll` 等当前范围数据和 DOM 就绪才绑定。一次建立当前 DOM 索引，滚动按帧合并，定位行用二分布局读取；滚动位置写入 ref 快照，不触发 App 整页重渲染。
- 坐标转换为 CSS 像素，避免入场 `scale(0.985)` 混入滚动距离。最多三帧复验屏外卡片展开后的布局，导航/卸载释放监听和帧；滚轮、滚动条及实际滚动可取消恢复，按钮、输入控件和 IME 操作不会误取消。
- 删除范围先清导航和 capture，再清缓存；旧 binding 的 `dispose()` 只清理资源，不读取新 DOM 回写旧模式。

会话快照重启后清空，不保存路径、图片数组、原图缓存、DOM、搜索或弹窗。持久作品续读仍使用独立的 `WorkReadingProgress`。单一大相册的完整详情元数据与篇目 DOM 仍可能较大；这轮没有将其改为虚拟书目，也不承诺固定帧率或超大图片解码耗时。
