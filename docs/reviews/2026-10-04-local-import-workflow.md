# 本地导入工作流验收

第一批落实 Serpent 的任务就地组织与逐步展开思路，独立实现，不复制外部代码。

- 确认前只选择文件，确认页可选现有相册，默认复用已知相同内容；高级重复策略折叠。同名不同内容保留，原文件不移动。
- 中间失败不会撤销成功项；逐项原因与仅重试失败项可达。停止保留成功项，继续浏览不取消后台任务。
- 主进程绑定窗口与随机 ID，Renderer 不能自行传路径开始导入。文件数、大小、格式、流式读取均有界；图像与相册关系事务提交，复用保留已有分析。
- 不同步遍历旧库计算指纹；范围明确为已有指纹与本批文件。暂不提供跨重启恢复，也不自动启动模型。

定向测试 7 项覆盖内容复用、独立保留、失败修复重试、取消、失效相册回滚、窗口隔离和旧指纹失效。完整门禁通过：82 个测试文件 / 413 项 TypeScript 测试、9 项 Python、类型检查与生产构建。

Windows 下全测试无限扩展进程导致既有文件夹具出现 5 秒超时；限制 Vitest 为 4 个工作进程后保持原断言与原时限通过。

真实窗口验收由 `scripts/smoke-navigation.mjs` 完成，49 组检查通过；使用临时图库与受控原生文件选择，检查导入确认、相册、重复复用、损坏文件修复后仅重试、取消与最小窗口布局。首次运行遇到调试协议 Promise 回收，重跑通过；截图已检查，结果与重试入口可见。
