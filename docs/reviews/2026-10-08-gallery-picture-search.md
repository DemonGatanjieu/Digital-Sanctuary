# 图库主页中文搜索验收

日期：2026-10-08。基线 `2d258fdc7ddad7d35a1300ff801d0f12e4251e1b`。范围：把常用画面检索放到图库主页，移除手动载入/扫描步骤，保留原有图库操作。

## 最终行为

- 图库横幅前的搜索框默认“搜画面”，输入中文后回车/找图一次提交即可；普通名称、画师、Pixiv ID 搜索在同一框切换。
- 主进程自动扫描当前图库筛选、建立或复用内容索引、逐步返回图片内容排序。只在用户提交时推理，不因进入图库或每次输入触发模型。
- 名称和图片候选共用 WorkQuery SQL 条件，涵盖 managed/external、喜欢、最近浏览、未分相册、类型、画师及相册 AND/OR/NOT。范围改变收起旧结果并提示重新搜索，不混用旧范围。
- 结果每次 60 件普通图库卡片，以最高相关页作为多页作品卡片与大图入口；显示匹配页身份，复制/拖出使用该页，作品级批量操作仍明确包含整件所有页。改名、喜欢、入册及移出后按真实 ID 更新元数据/成员条件。
- 图库索引单次上限 10,000 页，按 100 页读取候选；超过上限明确提示缩小范围，不默默声称搜索全库。原工作台 1,000 页和文件夹授权边界保持。向量仍按内容 SHA256 + 模型版本缓存最多 10,000 条。
- App 持有搜索状态，离页继续、回页复验所有已加载页；任务中心返回图库。清除和切换名称模式取消旧任务；旧启动/轮询/分页回包不能覆盖当前状态。失败保留提问、可直接重试，已完成索引保留。

## 边界

不自动扫描整个磁盘、移动图片、给所有图片打 WD 标签或启动聊天模型。图片内容模型仅对可读取的原图编码；外部缺失文件单独报失败，不作为“不含某元素”的结论。普通搜索条件可以保存，画面描述任务为当前应用会话，重启后重新提交即可复用内容索引。模型中心安装、GPU 找图和旧安装器重打不在本轮范围。
