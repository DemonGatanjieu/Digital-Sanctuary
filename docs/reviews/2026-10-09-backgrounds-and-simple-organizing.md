# 图库选图背景与整理流程整合

日期：2026-10-09。回滚基线：`482f6956093ae827992ba9a2b15f534450a54fdd`（开始时工作区干净）。范围：用户提出的图库横幅选图、首页背景，以及整理界面减负。

## 最终体验

- 图库“更换横幅”提供“从图库选择 / 选择本地图片”。图库选择器按名称、画师或 ID 搜索，先选作品再选具体页，明确确认使用；每次载入 60 件作品/60 页。支持输入法、键盘关闭、读取重试、忙碌锁定与迟到响应隔离。
- 首页“更换背景”共用选择器，可选另一张图，独立保存、独立恢复默认。主题色遮罩及实底任务卡保持文字清楚；900px 窗口保留背景内部留白，不加入新的背景动画。
- 整理页改为“来源与范围 → 想找什么 → 选结果处理”。输入描述即按画面检索，留空且没有附加元素时使用探索规则；仅附加元素时直接筛选。取消原先图库四种/文件夹三种查找分类和手动载入步骤，不要求先理解模型或缓存。
- “附加筛选条件”按需展开，需要/排除可与描述组合，当前已选条件仍可见。英文标签和阈值说明放入更深详情，不在首屏放调参滑块。相册建议与持久任务记录从次要入口展开；图库多选和任务中心仍直达原范围/记录。
- 进入图库仅读取预览，不分析；提交会自动扫描并分析。切换范围清空选择、收起旧结果与操作，重新提交后按新范围执行。返回页面恢复会话和描述，不重新运行模型。
- 描述结果与图库搜索共用 0.65 显示启发式，默认收起弱匹配；“全部图片”读取同一会话，不重复推理。不显示把余弦分数当正确率的数字。复制、按页入册、确认导入及携图讨论保留；移出按整件作品预览与确认，即使仅选一页也说明涉及全部页。

## 实现与边界

`ArtworkBackgroundControls` 与 `LibraryImagePicker` 共用 UI，`GalleryBannerService` 共用有界解码、编码和持久化。Renderer 的图库选择仅提交真实作品/资产 ID；主进程校验资产成员、图片类型和可用状态再读文件。仅应用窗口主 frame 可调用背景 IPC。32 MB / 3,200 万像素限制，独立 JPEG 最多 1,600×900；`library.banner.v1` 与 `home.background.v1` 互不覆盖。取消、缺失或读取失败保留旧图，原图不移动、不改名、不自动入库或分析。

`workbenchQuery` 只推导用户输入对应的条件；主进程仍验证范围和查询。新增 `workbench:run-library` 将扫描与显式提交衔接，窗口所有权及 main-frame 校验保留。工作台每批 1,000 图、扫描 20,000 个目录项、显示 60、选择 500、闲置授权 30 分钟的上限不变，图库主页搜索仍单独为 10,000 页。串行模型队列、取消、指纹索引和文件夹授权不变。移出复用现有预览令牌/回收站语义；外部引用只移除索引，已移出作品从终态工作台快照清理，避免重复操作。

旧的重复缓存查询/预设 UI 已移除，使用统一条件和有界分析流程；服务中的既有查询接口未在本轮删除。相册建议仍为独立持久任务，预览不推理、选择建议后才创建相册。工作台会话与文件夹授权不跨应用重启。
