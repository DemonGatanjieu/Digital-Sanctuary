# 点击反馈与减少动画覆盖

用户希望点击按钮有短促反馈。本批只增强现有控件，保持当前页面、功能入口和操作语义。

- 共享按钮、首页任务卡、导航、设置折叠入口有轻微按压/回弹；均衡 150ms，精致 190ms。业务点击立即继续，动画不承担加载/成功状态。
- 首页箭头有 3px 悬停反馈，设置展开和弹窗使用短淡入；弹窗背景只改变透明度，不移动整个遮罩。
- 同按钮快速连点取消旧动画；通过 WeakMap 管理，不使用 React 状态、计时器、逐帧监听、布局读取或全图库卡片入场动画，不引入动画依赖。
- 禁用按钮与作品表面不播放按压；键盘触发沿用同一点击路径。
- 应用减少动画、省电档和系统 `prefers-reduced-motion` 同时覆盖 body portal 的弹窗及伪元素。保留画册动画结束事件，避免等待 450–650ms 的降级计时器；焦点、选中和颜色反馈继续工作。
- 修复平移、渐隐、层叠抽拉的结束监听误挂在外层容器：转移到实际动画元素，保留自身事件判断，正常动画结束即可继续操作，减少动画时也能立即结束。隔离窗口测试工具同时等待 Electron API 初始化，避免 inspector 提前可用时启动失败。

完整门禁通过：439 项 TS / 9 项 Python、类型检查与生产构建。隔离 Electron 画册检查通过 33 组，覆盖 1280×720、900×620、返航与删除恢复，新增的三种减少动画策略分别检查四种翻页效果在 350ms 内结束（早于 450–650ms 降级计时器）；整库读取 0 次。导航通过 58 组，含五种动效策略、嵌套文字点击、快速连点不累积、布局不变，以及 body portal 的减少动画覆盖。5 项新增单测覆盖反馈策略与取消、禁用、portal 边界。

既有 0.1.2 安装包未重打，本批动效属于更新后的源码与开发构建。
