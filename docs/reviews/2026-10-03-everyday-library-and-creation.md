# 日常图库与创作闭环

日期：2026-10-03。回滚基线：`1fb1cc1`。本批将常用找图、续读和保存创作结果放进现有入口，继续减少等待、状态丢失和重复操作。

## 用户能直接使用的能力

| 操作 | 行为 |
| --- | --- |
| 喜欢、最近浏览、未分相册 | 全部作品中一键切换，也能通过 Ctrl+K 进入；页面内保留搜索、类型和相册范围，快捷面板直达时清空旧范围 |
| 最近浏览 | 按浏览时间倒序，离开该筛选恢复原来的字段与方向；没有记录时显示对应说明，不误报整个图库为空 |
| 从封面继续读 | 恢复该作品上次成功加载的图片页；显式点击相册或画师中的某页仍从该页开始 |
| 读图后关闭 | 立即关闭界面，后台合并写入最后实际加载的页，成功后刷新最近列表；失败图片不成为阅读位置 |
| 复制和保存创作 | 稳定回答可复制正文或保存 Markdown；整段会话可复制和导出，使用原生保存对话框 |
| 模型慢回复时切换 | 回答留在原会话，不抢回当前工作区、不覆盖另一段草稿；删除中止对应请求，失败重新生成保留旧回答 |
| 刚滚动完就切页 | 切换发起时同步读取位置，不依赖浏览器是否已经发送末次滚动事件 |
| 快捷面板隐藏后恢复探索 | 过期显示回包不再额外隐藏新视图；原生窗口焦点和显示状态有真实检查 |
| 900×620 小窗口写作 | 历史和设置各自滚动，聊天和输入区使用可用高度；长回答只在消息区滚动，不推走标题或输入框 |

新增能力沿用四个主入口，不增加顶层页面。分页去重后的游标按实际 SQL 返回数量前进，避免并发插入造成重复页和加载停滞。

## 持久化与来源

阅读位置复用 `works.last_viewed_at` 与 `library.readingProgress` 偏好；最多记录 100 件作品，每件只保存一个作品 ID、资产 ID 和时间。主进程检查资产归属、图片类型、可用状态及作品删除状态；失效资产和删除作品清理位置。没有新增模型任务或偏好训练信号，不修改原文件、保存时间和修改时间，也不升级数据库版本。

创作每条新回答保存实际模型、模型及运行时版本、参数、参考页和本轮耗时。导出明确区分每条回答来源和当前会话设置；旧回答未记录的来源不补造。处理中只导出已保存消息。输出 IPC 只接收会话和消息 ID，主进程重新读取内容；图片和本地路径不嵌入 Markdown。保存采用临时文件和原子改名，取消不产生文件。

烟测使用独立临时数据库和用户目录，不改真实图库、不安装或下载模型。原生可见性以 Electron `View.getVisible()` 检查，焦点同时检查原生 host input 与页面 `hasFocus()`；离线错误页的 `document.visibilityState` 可能仍为 hidden，不能用它代替真实子视图状态。截图保存在忽略的 `.tmp/navigation-smoke/`、`.tmp/viewer-smoke/` 和 `.tmp/inspiration-smoke/`。源码与生产构建已更新；本批未重打安装包。

## 下一批的实测方向

相册和画师当前仍使用旧页级整库读取；目录卡片逐项扫描全库，离开图库后详情身份和画册展对也会丢失。后续优先改成目录摘要与按范围读取，并保留已有画册和水族入口，再检查详情返回位置。具体差异、边界与分批提案见 [目录与范围读取评估](../research/2026-10-03-gallery-directory-scope.md)。语义检索、资料库和小组件需要独立验证模型、数据及执行边界，不在本批伪装成可用功能。
