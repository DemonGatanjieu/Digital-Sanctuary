## 实现

目录不再通过 `listArtworks()` 拉取全库后筛选。相册/画师使用分组聚合计数与排名预览；保存组合每次最多 12 条，按同一个作品级查询规则计数并返回有效包含/排除条件与已删除分类警示。普通相册区分作品总页数和实际收录 legacy 页数，部分页入册不扩成整作品页。

详情必选相册、画师或作品实体范围，未知作者明确用 NULL。页 DTO 保留真实 `libraryWorkId`、`assetId` 和 `pageIndex`；数字文件名本地作品不猜测合并。新目录大图根据真实作品 ID 读取全部资产，以点击页覆盖续读记录；无 legacy 页不制造页 ID，提供普通作品入口。查询/范围切换与取消使用请求代次，晚响应不能覆盖当前范围或重开大图。

相册选图每页 60 张、防抖 180ms，跨页保持最多 500 个页 ID；全选当前页只累加当前候选。一批一次事务写入，资产或相册失效、中途写入失败均回滚；弹窗失败保留选择。候选与整批验证要求资产状态 available，missing/trashed/error 不能入册；详情仍保留完整库存书目。封面验证按成员 ID 查询，旧兼容接口未删除，新目录不消费它们。

输入法 Esc 保留原生候选取消，不关闭选图弹窗；共享 DialogOverlay 只允许最上层消费 Esc/Tab，并尊重已处理事件、输入法和忙碌保护。作者与相册后台不处理上层弹窗的 Esc。初次平铺画师计数来自已有画师元数据，无需额外读取整个目录。

## 验证记录

- `npm.cmd run verify`：74 个 Vitest 文件 / 363 项 TS 测试、9 项 Python 测试、类型检查与生产构建全部通过。
- 导航 24 项、大图 14 项、创作 8 项回归通过。创作推理与剪贴板使用受控隔离夹具，未安装模型或修改系统剪贴板。
- 新目录烟测两轮共 10 组检查：每轮 10k 或 50k 件作品元数据（声明页数同量、元数据资产数为 0），另有 70 张真实小 PNG 页。253 个画师包含未知作者组；同数字前缀的两张本地页仍是两个独立作品。
- 从启动前 IPC 注册开始统计，到切换目录、打开范围、大图、失败重试、跨页批量入册完成，`library:list` 调用均为 **0**。相册只取实际 1 页、未知作者只取 2 页；批量实际一次写入 65 页后范围刷新为 66 页，失败请求未执行写入。
- 组合摘要首次 12 条、下一页 3 条；最多 12 条计算、4 张组合预览、3 张画师预览的边界由 SQL/IPC/测试共同覆盖。该窗口夹具的组合属于无资产元数据作品，所以组合预览为 0，不冒充真实海量图片覆盖。
- 900×620 选图弹窗宽 820、右边 860、底边 596；外层与网格横向溢出均为 0。截图在忽略目录 `.tmp/gallery-directory-smoke/`，已检查。
- Renderer 时间原点至相册 3 卡和组合 12 卡就绪分别约 581ms / 1107ms，JS 堆约 10MB。不是应用全程冷启动耗时，也不是 10k/50k 原图解码或帧率测量。
- 候选页先确定最多 200 个 ID，再读取当前页关系和 JSON；新增普通页顺序与 legacy 图片部分索引，schema 仍为 6。系统 Node / `node:sqlite` 的 10k 件 / 50k legacy 页探针，在同库同连接、同索引下各采 7 次，比较 JOIN 后分页与先限定 ID 两种 SQL 形状，中位约 119.67ms / 0.166ms（仅 `.all()`，不含 COUNT 与 DTO 映射）。包含精确总数的完整候选 API 仍约 114ms，相册 200 页范围约 9.3ms；不是历史版本全 API 对比。未控制冷缓存、未执行 ANALYZE、未独占机器，不据此宣称整个界面几百倍加速。可复查本地忽略目录 `.tmp/directory-page-comparison.mjs` 与 `.tmp/directory-replay.mjs`。
- 烟测启动改为临时 bootstrap，先安装仅隔离进程内的计数 spy 再加载原生产主模块；避免过早调试器评估 Node 内部。Windows Chromium 退出时偶发文件锁采用有界清理重试，最终各脚本退出成功。

## 保留的边界

- 导入返回、存储迁移、下载统计等兼容路径仍可能读取整库；本批只完成目录/范围/入册流程的替换。
- 单个相册或画师详情仍读取该范围全部 legacy 页元数据，保留完整展对、首页/末页和 TOC；超大单范围有待 manifest 分页。
- 范围选择保留在 App 会话内；详情子模式、展对资产与列表锚点的完整返航快照尚未实施。
- 元数据夹具不包含真实海量图片解码，不能据此保证固定帧率。
- 更新源码与开发构建，安装包重新打包和安装验收另属发行门禁。
