# 统一找图、文件夹筛选与原图取用

本批承接用户确认的后三项能力，保留“首页 → 找图与整理”一个入口，在原整理页切换“我的图库 / 本地文件夹”。没有新增一级导航或前端依赖。

## 实际操作

- 本地文件夹：原生选择后只预览。默认复用探索启用的规则，也可点选需要/排除的元素，或输入画面描述；包括子文件夹需显式勾选。
- 图库：按现有范围加载每一页，输入中文画面描述，结果按内容相似度排序；选中的具体页可加入相册。原有探索规则排查、特征查找和分类建议继续保留。
- 取用：图库多选、规则排查结果、工作台和大图作品信息均可复制原图到自选目录；单图可复制栅格供粘贴、定位源文件。作品级复制包含各静态图片页，工作台选择按具体页操作。
- 导入：文件夹中选中图片后，进入原有确认页选择相册与重复策略；只导入所选项，源文件不搬动。
- 返回：查找条件、结果与运行状态在当前会话保留，关闭页面不停止任务；侧栏任务中心可停止或返回。复制详情无需重新选择图片即可查看或重试。

工作台沿用共享按钮、分段菜单与折叠区。首屏突出来源、输入和查找动作；可选元素条件折叠，进度紧邻查找按钮，来源和图库方式宽窗并列。复杂标签、阈值与原始模型记录继续按需展开。

## 边界与资源

主进程持有原生文件夹清单，Renderer 只用窗口绑定的随机会话/图片 ID。扫描跳过链接，操作重新校验根及父目录；预览只返回最大 384px 缩略图。单批 1,000 张 / 20,000 个目录项，展示每次 60 张，选择最多 500 张；到达上限明确说明未扫描完。未分析、失败与匹配分开，不能把失败算成排除成功。

WD 沿用既有串行队列及探索规则。模型未就绪时拒绝元素任务，文件名开发探针不能冒充成功识别。会话标签缓存绑定内容指纹与模型版本，图像在分析期间变化使结果失败并清除缓存。

画面描述使用已经准备的 EmbeddingGemma 2 独立 CPU 环境，离线校验和加载固定快照；纯描述不调用 WD，附加明确元素条件才组合使用，不需要大型聊天模型。归一化 768 维向量存入独立 `semantic-index.db`，按 SHA-256 + 模型/预处理版本复用，最多 10,000 条；模型闲置 60 秒释放。最终窗口试跑中，首次加载、查询及三张合成图编码共 81.7 秒，复用三条向量的第二次查询共 901ms，不能将独立 GPU 探针速度当作应用 CPU 查询速度。

原图复制排他创建、同名追加序号、前后 SHA-256 校验，保留已有文件、源文件和成功项，失败/未处理项可重试；缺失原图按页报错。剪贴板为可能缩小的栅格副本，最大输入 32MB / 32MP、长边最多 4096px，解码前有界读取文件头，小图不放大；未知格式提示改用原图复制。任务与临时授权不跨重启续跑，闲置 30 分钟过期，不承诺异常退出后的复制自动恢复。

## 验证

- `npm.cmd run verify`：94 个测试文件、466 项 TypeScript、9 项 Python、完整类型检查和生产构建通过。新增 22 项行为测试覆盖输出冲突/原字节/停止/失败重试、跨窗口授权、链接替换、扫描上限、按页范围、缺失文件、内容与模型变化、缓存复用及真实模型就绪边界。
- `npm.cmd run smoke:image-workbench`：14 组通过。隔离临时图库，原生选择框仅替换返回路径，实际生产 IPC、WD、EmbeddingGemma 2 CPU 与系统剪贴板。覆盖文件夹不自动入库、中文月亮/红方块首位排序、向量复用、同名原图保护、所选导入、逐页入册、整件多页复制及任务返航；模型冷加载时任务中心仍可操作，查询与运行状态可恢复。1280×720 查找按钮首屏可见，1280 / 900 窗口无横向溢出，深色输入对比度至少 4.5:1。合成图片与目标目录均为测试文件，剪贴板测试前备份并恢复。
- `node scripts/smoke-navigation.mjs`：59 组通过，覆盖原整理方式、首页、任务中心、探索原生遮挡、缩放、输入法、主题与焦点。
- `node scripts/smoke-viewer.mjs`：20 组通过，两套大图的作品信息、图库改名、相册、续读及键盘保持正常；900×620 信息层无溢出。

开发过程中一次完整门禁的两个既有数据库大夹具超过默认 5 秒，未修改超时阈值，随后完整复跑通过。查看器一次 CDP 鼠标事件超时，完整复跑通过。工作台布局烟测移除对后台窗口可能暂停的动画帧等待，直接读取实际布局并在截图前恢复测试窗口；没有放宽产品断言。
