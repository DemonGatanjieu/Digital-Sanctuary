# 作品信息整合验收

两种大图使用同一作品信息层；来源、文件、当前相册、已有分析与生成来源从作品上下文可达。低频记录、原始标签及版本折叠，保留既有工具的快捷入口。相册操作明确按整件作品归档，原文件不移动。

信息读取只从 SQLite 取已有结果，不调用模型、不发送图片。主进程按作品 ID 与合法页序号查询；跨作品的资产识别结果不可混读，删除作品不返回记录。已有识别注明保存时的模型，不声称为当前重新识别。

定向检查覆盖作品/页隔离、删除、输入边界与不创建分析任务；完整门禁通过 83 个测试文件 / 415 项 TS、9 项 Python、类型检查与生产构建。真实查看器脚本 16 组检查通过，包含两种入口的只读信息、移出再加入相册、900×620 无横向溢出、背景翻页冻结、输入法 Esc 和最上层关闭；原缩放、拖动、续读、重启及旧响应隔离检查继续通过。信息较长时在本层滚动，截图已检查。
