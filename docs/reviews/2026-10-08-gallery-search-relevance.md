# 图库搜索默认相关性筛选

日期：2026-10-08。基线 `c5b957b433710fade602cd57ef7764fbb1c0f471`。范围：图库主页画面搜索默认收起较低相关性候选，提供就地恢复入口。

## 最终行为

- 默认“较相关结果”，不再把每张成功分析的图片都作为匹配结果呈现。搜索框下显示收起的作品数，点“显示更多”展开，随时可切回“只看较相关结果”。
- 主进程依据每件作品最高分的实际页筛选，再分页；匹配图片数只计达到门槛的页。收起数量遵守当前喜欢、相册、保存方式等数据库条件，不包含读取失败或已经不属于范围的作品。多页作品大图仍可翻阅全部页，作品级批量操作仍处理整件作品。
- 展开/收起只读取已有会话，不重新扫描、加载模型或编码图片。切换重置分页及多选，旧轮询/分页不能恢复上一范围；离页返航保留当前显示范围。新查询、清除和切换名称模式恢复默认。
- 所有候选都低于门槛时明确留空，提示换描述或“显示更多”；不为填满页面悄悄放宽条件。失败、取消和未分析仍与低相关性分别呈现。
- 原整理工作台的明确元素筛选、文件夹流程和探索保护不受这项图库显示策略影响。

## 门槛与限制

当前 EmbeddingGemma 2 使用余弦相似度 **0.65（含边界）** 作为可逆的显示启发式，不是校准的置信度、65% 正确率或明确元素命中保证。常用界面只提供展开/收起，不暴露精确模型参数。

既有真实离线三张合成图证据中，中文对应图分数约 0.709–0.752，非对应图约 0.536–0.609，因此采用 0.65 作为本模型初始门槛。证据来自 `.tmp/semantic-smoke/result.json`，仅验证少量合成图；没有对用户二次元图库作准确率校准。描述过于笼统、模型对某种画风不熟悉时，相关图也可能被收起，用户可展开查看。后续换模型必须重新检查分数范围；不能沿用概率含义。

- 定向服务/Controller/IPC：25 项通过。新增回归覆盖门槛等值/略低值、过滤后 60 件分页、全弱匹配、即时成员条件变化、展开不重复编码、非法显示范围/越权，以及旧分页不能覆盖新显示范围。
- `node scripts/smoke-gallery-search.mjs`：真实离线 EmbeddingGemma CPU、临时隔离 SQLite 与合成图片，10 条流程通过。夜景搜索只显示 1 件作品 / 1 张匹配页，收起 2 件作品 / 3 张弱匹配页；展开恢复 3 件作品 / 4 张成功候选，同一任务与 3 条内容索引保持。外部范围夜景搜索为零匹配，空状态可展开恢复两件外部作品。
- 同一窗口覆盖中文输入法、停止首次模型加载、任务中心返航、最匹配第二页大图、导航保留展开范围、新描述恢复默认、名称模式及清除、900×620 亮/暗主题。已查看实际截图，收起说明与按钮可读、未被遮挡。当前合成小样本冷启动约 41.8 秒、复用换描述约 1.32 秒，不代表个人大图库性能。
- 首次窗口验收在等待整个反馈区域的进度文字时超时，截图已显示完成；将结束条件限定为实际进度的 `role=status` 后重新完整运行通过。失败路径增加反馈文字、页面可见性和主进程阶段诊断；没有放宽模型门槛或在零结果时补入弱匹配。证据位于忽略的 `.tmp/gallery-search-smoke/`，不读取用户图库。
