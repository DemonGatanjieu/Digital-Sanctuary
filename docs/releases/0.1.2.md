## 使用变化

新版首页按今天要做的任务直达；整理默认沿用探索的元素规则，高级参数按需展开。探索页就地管理拦截内容和模型，设置按用途归并；新增可预览的本地导入、共享作品信息、保存筛选与统一任务入口，并整合此前的图库分页、查看器和窄窗体验改进。

旧版图片可以继续保存在 C 盘。选择新保存位置时，可“复制旧图片并切换”：先备份数据库，复制并逐文件校验，成功后更新索引，保留原图。同名不同内容不覆盖，失败不切换路径。旧版作品 ID 目录无需重排；生成结果、备份、导出和外部引用保持原位置。

完整步骤、范围及智能体协助任务文本见 [旧版升级与图片迁移](../operations/UPGRADE_AND_STORAGE_MIGRATION.md)。先备份再覆盖安装，不必卸载；升级后不建议直接降级使用旧库。
