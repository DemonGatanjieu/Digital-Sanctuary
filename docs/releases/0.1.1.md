# 纯净领域 0.1.1：保留数据的覆盖升级版

- 发布日期：2026-08-27
- 安装包：`Digital-Sanctuary-Setup-0.1.1.exe`
- 升级方式：关闭旧版后直接运行新版安装器，覆盖原安装目录；不要先卸载

## 这次主要解决什么

- 模型启动失败时不再把探索页每张图片都伪装成“命中规则”；应用会显示统一的模型故障状态，并暂停受保护探索。
- 远程图片的 `allowed / blocked / unavailable` 状态分离，只有完整模型结果真正命中用户规则才显示为拦截。
- 画廊、相册、画师馆藏、水族馆和本地大图始终是可信本地内容，不受探索遮罩影响。
- 修复部分 Pixiv 图片加载、元素透视、作者头像、作品下载与画廊预览问题。
- 增加显式双向偏好、Prompt Bridge v2、本机 ComfyUI 桥接，以及画师馆藏元素分析和应用内画师主页跳转。

## 覆盖升级步骤

1. 在旧版设置中使用“备份数据库”；若旧版无法操作，也可以在完全退出应用后复制 `%APPDATA%\digital-sanctuary` 整个目录。
2. 确认任务管理器中没有 `DigitalSanctuary.exe`、`electron.exe` 或 `sanctuary-vision.exe`。
3. 不卸载旧版，直接运行 `Digital-Sanctuary-Setup-0.1.1.exe`。
4. 安装目录选择旧版所在目录。安装完成后启动一次，等待界面显示本地 WD Tagger 已就绪。
5. 检查画廊作品数、作者、相册与下载目录。如果自定义下载目录位于其他磁盘，保持原目录不动即可。

## 数据为什么不会丢

- SQLite 图库、分类、偏好和 Pixiv 登录 session 位于 Electron 用户数据目录，不位于程序安装目录。
- 下载原图位于用户选择的图片目录；默认是“图片\Digital Sanctuary\Pixiv”。
- 新安装器沿用相同的应用 ID `moe.silverloli.digital-sanctuary`，覆盖升级不会创建另一套用户数据目录。
- 数据库迁移是幂等的；新版可以读取并升级旧库。升级后不建议直接降级运行旧版。

## 注意

- 当前安装包没有商业代码签名证书，Windows 可能显示“未知发布者”或 SmartScreen 提示。
- 如果旧版安装在不确定的位置，先右键旧版快捷方式查看目标路径，再把新版安装到同一目录。
- 不要删除 `%APPDATA%\digital-sanctuary`，也不要移动已经下载的图片目录。
