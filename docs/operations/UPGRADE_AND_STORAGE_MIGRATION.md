# 旧版升级与图片迁移（0.1.2）

适用于早期版纯净领域用户，包括图片仍保存在 C 盘的情况。升级程序和搬迁图片是两件事，可以先升级、确认图库正常，再决定是否迁移。

## 给朋友的安装步骤

1. 先备份数据库和原图。旧版能打开时，使用设置里的“备份数据库”；不能打开时，完全退出应用后复制实际用户数据目录，保留 `library.db` 及同目录的 WAL 文件。早期版本通常在 `%APPDATA%\digital-sanctuary`，以本机实际文件为准。数据库备份不包含原图。
2. 完全退出旧版纯净领域及它的视觉进程。直接运行 `Digital-Sanctuary-Setup-0.1.2.exe`，选择旧程序所在的安装目录覆盖升级，不必先卸载。程序安装目录与图片保存目录可以在不同磁盘。
3. 首次启动等待图片识别模型就绪，检查作品数量、旧相册、作者和多页作品。安装包内含 CPU WD Tagger 与独立运行时，无须另装 Python。
4. 暂时不移动图片也能使用。图库沿用数据库中记录的原路径，C 盘旧图片不会因为安装新版而自动搬家。
5. 如果旧图库没有出现，先停止迁移并检查是否打开了另一个 Windows 用户或另一套应用数据目录。不要把“空图库”误当成图片丢失，也不要先把原图重新导入。

安装包尚未配置商业代码签名，Windows 可能显示未知发布者。请核对随包 SHA-256 文件及来源。

## 推荐：由应用复制迁移

1. 在“设置 → 图库与存储”更改作品保存位置，选择容量足够的新文件夹，例如 `D:\Digital Sanctuary\Pixiv`。复制期间需要同时容纳新旧两份图片。
2. 在确认框选择“复制旧图片并切换”。应用先在用户数据目录的 `Backups` 下生成数据库快照，再复制图库索引中的图片、缩略图及作者头像，逐文件比较 SHA-256；成功后事务更新图库路径。
3. 迁移保持原文件名与相对目录：旧版 `Pixiv\作品ID\图片` 可以继续使用，无需先重排为画师目录。新下载采用当前版本的目录规则，已有旧作品目录仍可复用。
4. 同名但内容不同、原文件缺失、目录相互包含或不安全的子目录链接会停止迁移，不覆盖冲突文件，不删除原图。失败时图库路径保持不变；目标可能留下已校验的副本，重试可以复用相同内容。
5. 完成后重启，抽查旧相册、收藏、多页作品和大图。原文件仍在 C 盘，迁移完成不会自动释放旧盘空间；确认备份及新图库正常后，再自行决定是否清理旧副本。

此入口处理所迁目录下**已入库**的图片与关联头像。未入库文件、外部引用图片，以及 `Generated`、`Backups`、`Exports` 中的既有文件保持原位置，不会整盘扫描或按推测搬走。若此前已经仅切换下载位置，备份与迁移区域可将默认旧目录中仍被图库引用的图片复制到当前保存位置；其他旧自定义目录需要先核对实际路径。

## 让朋友的智能体协助时

可以协助，但不能只按文件名把图片搬走。图库同时维护作品、资产、缩略图、头像和相册关系；文件搬走而数据库仍指向 C 盘，会出现空封面和打不开的大图。优先让智能体使用上面的应用入口，保持旧目录结构。画师/相册视图是图库元数据，不要求先按画师重命名磁盘目录。

可把以下任务说明交给朋友的智能体：

> 帮我将纯净领域的旧图库从 C 盘迁到我指定的新目录。先只读确认应用版本、实际用户数据目录、SQLite 库、现用图片根目录和目标目录，列出作品/图片数量、缺失文件与同名冲突；不要假定我的用户名、作者名、目录或数据库结构。优先使用 0.1.2 的“复制旧图片并切换”，保留原文件名和相对结构。迁移前备份数据库和原图；数据库在线备份使用应用快照，离线复制须先完全退出应用并保留 WAL。空间不够、源文件缺失或内容冲突时停止并说明具体问题，不覆盖文件。若确实必须离线适配，在数据库备份副本上先验证方案，生成旧路径→新路径清单及逐文件 SHA-256，先复制、校验，再按实际 schema 在事务内更新所有相关路径，包括 artworks.path、assets.path、assets.thumbnail_path、artists.avatar_local_path 和存储偏好；保持作品/资产 ID、页码、相册、收藏、来源与识别结果不变。不要删除原文件，不要把外部引用、生成结果或未入库文件一并推测搬迁。完成后重启应用，检查数量、相册、收藏、全部多页路径和抽样大图；给我迁移清单、校验结果、备份位置和恢复步骤。清理原目录另行征求我的明确同意。

如果早期版的文件曾被手动移动，先恢复到数据库记录的原位置，或依据实际文件和备份进行针对性修复；不要对正式库执行未经验证的通用 SQL 字符串替换。

## 这个安装包的范围

包含已经完成的任务首页、简化整理台、可预览的本地导入、作品信息、保存筛选、任务入口和安全存储迁移。新讨论的自然语言图片筛选、EmbeddingGemma2、多站点自定义探索和新的图片批量导出流程尚未接入。
