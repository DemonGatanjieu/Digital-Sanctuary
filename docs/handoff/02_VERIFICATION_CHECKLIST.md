# 交接二：验收清单

## 每次改动必须执行

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

`npm.cmd test` 已包含 Vitest 与 Python `unittest`。Python 虚拟环境启动器在受限沙箱中可能需要授权执行，这不等于虚拟环境损坏。

## 启动与窗口

- 新工作流：`npm.cmd run smoke:discovery` 验证默认复制导入、引用导入、同内容重新定位、错误文件拒绝、网址/快捷站点、网页原图与来源入库、900px 布局、图库选图与文件夹先导入后讨论。该烟测控制网站响应和原生选择/菜单边界；另用真实网站手工验证右键原图、登录/防盗链失败提示，用已安装的 Gemma/Qwen 实测 2–4 张图的内容区分和显存。

- 图库快用：运行 `npm.cmd run smoke:gallery-actions` 验证常驻改名、复制、拖放 IPC、横幅持久偏好、保存方式筛选、900px/1280px 布局与暗色文字对比度。该隔离烟测替换原生 `startDrag` 的系统接收边界；另手工把单页/封面拖到资源管理器和常用软件，确认原件保留，并检查不支持接收时的行为。

- 发布安装包须运行 `npm.cmd run dist:win` 与 `npm.cmd run smoke:installer`；测试使用隔离库，覆盖早期双页作品/相册升级、同名冲突、复制迁移、备份、原件保留、收藏与重启。实际用户升级步骤见 `docs/operations/UPGRADE_AND_STORAGE_MIGRATION.md`。

- 双击 `E:\PIxiv\启动纯净领域.cmd` 能启动构建版；失败时保留终端输出，不应无提示闪退。
- 重复启动只唤醒现有窗口，不创建第二个 Electron 主进程或第二份 Pixiv session。
- 构建更新后关闭旧进程再启动，确认窗口加载的是最新资源。
- 默认窗口、最大化和从探索返回画廊时布局没有横向溢出。

## 探索页烟雾测试

- 应用进入“探索”后保留精简侧栏，Pixiv 填满剩余内容区。
- Pixiv 顶层页面正常加载；邮箱登录和持久化 session 正常。
- 工具栏显示审查中、队列、放行、内容拦截、缓存和广告拦截计数。
- 真实普通作品图片 `naturalWidth > 0`，不会因邻近 `PR`/BOOTH 内容成片消失。
- 真正命中元素规则的图片显示占位层和命中原因，不出现原图闪现。
- “仅本次查看”只放行明确点击的单张 URL，不写入永久缓存。
- 非 Pixiv 顶层跳转、弹窗、下载、第三方 iframe 和非必要权限仍被拒绝；登录所需 reCAPTCHA 不被网络规则误拦。
- 第一方广告当前不作为通过条件；不得为了隐藏它恢复宽泛 DOM 猜测。

## 下载闭环专项

- 只有作品详情页启用“保存当前作品”；同一作品的全部页面均保存，不能抓取页面上其他作品图。
- Pixiv 网页内“保存到本地画廊”按钮与应用侧栏按钮行为一致，并校验当前作品 ID。
- 只有收藏作品页启用“下载全部收藏”；开始前显示总数并要求确认。
- 收藏任务分页读取公开和非公开作品，进度区分作品数、页数、跳过和失败。
- 进度标题只有零失败才显示“下载完成”；混合结果显示“部分完成”，作品已处理数等于成功与失败之和。
- 429、连续网络错误或连续 5 个作品失败会停止批次并显示原因，不继续把剩余作品全部记为失败。
- 文件保存到“图片/Digital Sanctuary/Pixiv/作品 ID”，使用临时文件和原子改名；同一路径存在时跳过网络下载。
- 网络任务并发不超过 4；大图流式落盘，不把多张原图同时完整读入内存。
- 单作品和收藏批量下载都直接标记用户信任，不运行 WD Tagger，不保留旧模糊/隐藏 assessment。
- 重复下载已存在作品时不重复网络传输，但会补齐索引、作者、标题、作品 ID 和页码。
- 未登录、无权访问、URL 非 Pixiv、响应结构漂移或内容类型错误时明确失败，不写入半成品记录。

## 画廊专项

- 大图库打开时不一次性解码所有原图；离屏图片保持懒加载。
- 平铺模式保留，清晰作品卡片不出现“已放行”覆盖字样。
- “作者 → 作品”模式首先显示作者封面墙，而不是纵向展开所有作者。
- 点击作者进入本地作者作品页；返回“全部作者”后滚动和选择状态正常。
- 同一 Pixiv 作品的多页聚合在一起，页码顺序正确；缺少来源元数据的旧图片仍能在平铺模式访问。
- 点击图片打开大图层；左右按钮、方向键、`Esc` 和背景关闭均正常。
- 大图层中的模糊/隐藏策略不会因放大动作被悄悄改成永久允许。
- 分类选择和现有集合关系仍可用。
- 点击分类卡进入分类详情；选择“设为分类封面”后返回封面墙能立即看到变化。
- 下载完成或从探索切回画廊后，作者本地头像与新增作者无需重启即可刷新。
- 画师馆藏的套图、翻页画集、水族漂浮与篇目编目入口打开大图后，都能按真实本地作品和当前页执行元素透视。
- 点击画师资料中的 `pixiv/画师ID` 胶囊会切换到应用内探索并打开官方画师页，不新建失控的 Electron 窗口，也不允许跳往非 Pixiv 地址。
- “作者 · 作品”中的“补全作者头像”只请求作者资料与头像；完成后本地 `avatars` 目录、数据库路径和作者卡片同步更新，不重新下载作品或触发 AI。

## 显式模型整理专项

- 应用启动、打开画廊、滚动和下载都不会自动创建整理任务。
- 开始前明确显示范围和图片数量；用户取消确认后没有后台推理。
- 可信作品分析后仍保持清晰，展示决策不被 assessment 覆盖。
- 结果显示模型与版本、标签、置信度和失败原因；自动建议与用户确认分类可区分。
- 尚未开始的任务可取消；重启后不会未经确认自动占用 GPU。
- 完整结果可按文件与模型版本复用，失败/取消结果不伪装成成功缓存。

## 元素透视、提示词整理与 ComfyUI 本地桥接专项

- 在本地画廊打开作品的“元素透视”，能在“看懂画面 / 整理提示词 / 设置探索拦截”之间切换，右侧面板没有横向溢出、嵌套滚动或底部动作被遮挡。
- WD 标签百分比明确说明为识别把握；切换 Danbooru、SDXL 插画与 FLUX 自然语言配置时不会把该百分比伪装成提示词权重。
- 每个 WD 标签能够明确切换“正向 / 忽略 / 负向”；切换作品、页或模型后本图选择重置，不跨作品积累。
- 输出格式、个人负向提示词库、主动保存的本地预设和复制按钮可用并可恢复；收藏、下载与浏览不会自动修改这些设置。
- 探索中的远程图片不能直接发送给 ComfyUI；必须先由用户明确下载为本地可信资源。
- 设置页只接受 `http://127.*`、`http://localhost` 或 `http://[::1]` 回环地址，远程地址、账号、路径、查询参数均被拒绝。
- 只接受 ComfyUI “API Format” JSON；超过 2 MiB、无节点、危险绝对路径/`..`、无正向提示词绑定的模板被拒绝。
- 只有显式启用桥接、选择模板并点击“显式发送当前页”后才上传参考图和提示词；不使用参考图的模板不上传图片。
- 任务状态持久化；异常退出后旧 `running` 任务标记失败，不会静默重跑。取消操作明确说明只停止本地等待。
- Mock ComfyUI 契约覆盖连接、排队、历史与下载；生成输出校验 MIME、体积和文件签名后原子落盘。
- 返回的所有栅格输出作为用户主动导入的可信资源进入画廊；打开生成作品可查看来源作品、正负提示词和工作流摘要。
- 区域级遮罩仍未接入生产；当前 WD 标签没有坐标，评审门槛见 `docs/research/REGION_LEVEL_MASKING_GATE_2026-08-24.md`。

## 缓存与性能

- 首次访问远程图片运行模型；同进程刷新和重启后能命中对应缓存。
- 修改元素规则或模型版本后旧远程缓存不产生错误 allow 快路径。
- 模型失败时探索页保持遮挡，数据库不保存永久失败记录。
- 状态栏显示实际视觉 provider；CUDA 初始化失败时明确回退 CPU。
- 不把下载并发和模型并发混为一谈；提高模型并发前必须重新基准测试显存、P50/P95 和 UI 响应。

## 模型中心与本地六维评论

- 首次启动不会自动下载 Qwen；只有在“模型中心 → 六维评价”显式点击后才下载权重、视觉投影和固定运行时。
- 下载中取消再继续可续传；声明大小或 SHA256 不符时不能进入正式模型目录。
- 启用 Qwen 必须先通过本地健康检查；作品雷达里的“标准六维”和“AI 自选六维”均可完成并显示本地模型来源。
- 重新运行任一 AI 六维后，雷达上方显示“模型眼中的画面”；“可见事实”和“主观解读”分区展示，不确定项默认折叠，历史雷达结果没有新字段时仍正常显示。
- 自选六维必须恰好六项、标签不同、带可见证据且不能全为 0；不合规回答应显示本次失败而不是保存空雷达。
- 点击“停用并释放”后不再把该模型作为雷达默认来源，随后可以删除模型文件。
- 本地评论模型失败、缺文件或超时不影响探索遮罩、个人偏好或画廊可信显示。

## 安全回归

- 不出现内嵌 Google OAuth、UA/`navigator.webdriver` 伪装或系统浏览器 Cookie 复制。
- `nodeIntegration` 保持关闭，sandbox、context isolation 和 web security 保持开启。
- 远程 Pixiv 页面不能访问本地文件、SQLite、视觉进程或通用 IPC。
- `sanctuary-image` 只读取数据库已索引且存在的路径，或原生授权文件夹随机会话内的有界缩略图；文件夹链接及过期授权不能继续读取。
- 未知远程图片不能先显示后审查；主动下载信任不能反向放开探索页未知内容。
- 广告过滤不能通过封禁整个 `pixiv.net` 或 `pximg.net` 实现。

## 本地找图工作台

本地找图工作台另用 `npm.cmd run smoke:image-workbench` 验收（先构建并准备独立语义环境和合成测试图，见 `services/semantic/README.md`）：

- 选择文件夹仅预览，默认不递归、不分析、不导入；上限和扫描不完整明确显示。
- WD 复用探索规则；明确元素失败或未分析不能记成排除成功。中文描述排序复用内容向量，不声称正确率。
- 所选图片进入原有导入确认；图库每一页参与查找，仅选中页入册。
- 原图复制保留原字节与源文件，同名另存，部分失败和停止后可重试；剪贴板小图不放大，大图与未知格式有明确边界。
- 返回页面恢复会话与条件，不自动运行模型；任务中心可停止和返回复制/查找详情。
- 1280 / 900 窗口、深色输入与操作区可达，最上层弹窗拥有键盘。

## Git 提交前

- 检查 `git status --short` 和 `git diff --check`。
- 确认没有 `node_modules/`、`.venv*`、`models/`、`.tmp/`、`apps/desktop/out/`、数据库、日志或账号 session。
- 提交信息说明行为变化；功能阶段和文档同步尽量分成可回滚的独立提交。

## Windows 发布

- `npm.cmd run pack:win` 生成的解包版可启动，状态页显示 `wd-swinv2-tagger-v3` 而不是开发探针。
- `npm.cmd run dist:win` 生成 NSIS 安装包，模型、标签表和自包含视觉运行时均在 `resources` 中。
- `npm.cmd run smoke:installer` 完成隔离安装、启动、模型整理页检查、卸载和临时目录清理。
- 在“设置 → 画廊与存储”创建 SQLite 备份；按 `docs/operations/BACKUP_AND_RECOVERY.md` 做一次离线恢复演练。

- 图库直接中文搜索：`npm.cmd run smoke:gallery-search` 使用真实本地 EmbeddingGemma 与隔离合成图片，验证单次提交自动索引、中文排序、索引复用、停止、匹配页、筛选、名称模式、返航和 900×620 布局。
