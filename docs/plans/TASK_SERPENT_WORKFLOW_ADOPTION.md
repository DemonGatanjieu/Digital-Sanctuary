## 本轮顺序与验收

1. 导入反馈与重复处理：原生文件选择后就地选择相册和重复策略；逐项结果、取消、仅重试失败项；图库可渐进刷新，模型不自动运行。
2. 统一作品信息：来源、相册、文件信息、已有识别和画评从作品上下文可达；窗口窄时使用单一抽屉，保留现有查看与分析语义。
3. 保存常用筛选：在已有作品查询上保存与恢复条件，不复制图库或人工维护成员；有清晰条件摘要与删除入口。
4. 统一任务入口：汇总适用的下载、导入、缩略图和分析状态，提供各类实际支持的操作，不把不存在的暂停/恢复能力做成假按钮。

每批完成定向测试、完整 `npm.cmd run verify`、真实隔离窗口验收与本地提交；稳定提交哈希另记里程碑。先闭合一批再推进下一批。

## 边界

不自动搬动外部原文件、不启动图库模型分析，不实施插件市场、云同步、通用多格式支持或 MCP。数据库后台进程迁移只在真实负载证据支持后另行设计。本轮采纳交互与流程思路，不复制第三方代码。
