# 现行路线：收紧与补充

- 状态：进行中（唯一现行路线）
- 开始：2026-10-10
- 定位与取舍规则：根目录 [`AGENTS.md`](../../AGENTS.md) 第 0 节（进 → 存 → 找 → 用）
- 上一条路线：[图片优先重设计](../design/IMAGE_FIRST_REDESIGN.md)（已完成，0.2.0）

## 为什么调整

项目起源于“P 站按标签筛选不可靠，按画面避雷”。有了本地模型之后，更大的价值在于让收藏的图片好找、好用。功能却沿着多个方向铺开，创作、画评、主题、字体各自成了一摊。这条路线先收紧，再沿“找”和“用”补强。

## 已定决策（2026-10-10，用户确认）

| 问题 | 决定 |
|---|---|
| 核心 | 围绕图片的搜索、管理和使用发挥价值；不是拼素材软件 |
| 探索避雷 | 保留为图片来源，维持质量，不再加功能 |
| 整理页 | 并入图库：找图只有一个地方 |
| 创作 | 改为从图出发；写小说、角色设定、世界观等与图片关系弱的方式保留，但放到次要位置 |
| 六维画评 | 并入作品信息，改为“读图”：画面描述、元素标签、可复制的提示词 |
| 主题 | 删除主题商店、主题包导入和另外三套主题；只保留默认主题，跟随系统浅色 / 深色 |
| 字体 | 只保留少数几种；去掉多槽位字体设置 |

## 顺带的工程项（从上一条路线移来）

- `main/index.ts` 的 `registerIpc()`（约 1,200 行）按领域拆分；删除功能时优先把对应部分移出。
- `database/src/index.ts`（约 3,000 行）按仓储拆分。
- `registerIpc()` 中接收 ID / 查询对象的处理器逐个补齐结构校验。

## 不在本路线

- 多站点通用探索。
- 新的装饰性界面、主题或动效。
- 与图片无关的 AI 功能。
