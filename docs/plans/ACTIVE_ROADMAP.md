## 当前施工任务

### T1：个人标签偏好与 Prompt Bridge（当前施工）

- 任务书：[`TASK_PERSONAL_TAG_PREFERENCE_AND_PROMPT_BRIDGE.md`](./TASK_PERSONAL_TAG_PREFERENCE_AND_PROMPT_BRIDGE.md)
- 状态：P1 代码实现与自动验证完成，等待正常重启后的真实 Pixiv 验收；P2～P4 仅为后续边界。
- 当前目标：实机校准“少看类似”的卡片热区、候选标签体验和个人偏好遮罩，再决定是否进入 P2 标签调音台。
- 当前边界：只影响远程探索；不改变主动下载和本地画廊的可信显示，不在本阶段连接 ComfyUI，不做局部区域遮罩。

验收顺序：

1. 放行作品能够选择不喜欢的候选元素；
2. 主进程从已保存 assessment 重新验证标签，网页不能伪造权重；
3. 一次反馈只产生有界变化，重复反馈逐渐增强；
4. 每次变化透明显示并可即时撤销；
5. 偏好命中只产生真实 `blocked`，模型或网络失败仍是 `unavailable`；
6. 重启与模型版本切换后持久化边界正确；
7. 本地画廊全入口保持无条件清晰。

### 已完成：探索保护可信边界

- 状态：代码实现完成，自动测试通过，等待真实 Pixiv 与新安装包验收。
- 已完成：本地画廊所有模式不再读取隐藏/模糊结论；导入和主动下载均为可信本地资产。
- 已完成：视觉进程 `health-check`、模型身份验证和内置小图启动推理；未就绪时显示一个总故障页。
- 已完成：探索结果拆为通过、真实命中和未能检查；重新启用视口优先队列。
- 已完成：“仅本次查看”不学习；“这张不该隐藏”永久放行具体页、按具体标签渐进调值并提供即时撤销。
- 已完成：偏好阈值按模型与模型版本隔离，规则指纹自动使旧缓存失效。

验收顺序：

1. 本地画廊卡片、相册、画师页、水族馆和大图在旧 `blur/hide` 数据下仍保持清晰；
2. 正常模型启动时显示“模型启动中”，完成启动推理后才出现 Pixiv；
3. 删除或损坏安装目录中的模型副本，确认只出现一个模型故障页；
4. 在真实 Pixiv 瀑布流长滚动，确认等待、通过、真实命中和单图失败不会互相冒充；
5. 点击“这张不该隐藏”，核对具体页永久放行、阈值变化提示、撤销和重启后的持久性；
6. 重建 NSIS 安装包并执行 `smoke:installer`。

## 维护规则

1. 同一时间只允许一个任务处于代码施工状态。
2. 来源草案负责表达想法，执行版负责工程边界；冲突时以经过评审的执行版为准。
3. 每阶段必须执行 `npm.cmd run verify`，单独提交并等待验收。
4. 已完成任务移入 `docs/plans/archive/`，不删除 Git 历史和验收证据。
5. 未解决问题进入 `docs/known-issues/` 或带状态的审计账本，不从计划中静默消失。
6. 新能力不得破坏主动下载可信、显式模型分析、Renderer 无任意文件路径和远程 Pixiv 隔离等既有边界。
