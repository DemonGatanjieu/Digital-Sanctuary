- 已完成：雷达同时提供“标准六维”和“AI 自选六维”。自选六维由模型按当前作品命名，并通过六项数量、唯一键/标签、逐项证据、非全零与 JSON 结构门禁。
- 保持未接入：Anime Aesthetic Classifier 仍只展示来源，不提供假安装或假评分按钮；它是独立候选，不影响本阶段完成状态。

实机验收：

1. 打开“模型中心”，确认内置模型为当前使用，未自动下载额外权重；
2. 下载 ConvNeXt 后切换，确认探索保护恢复 ready；切回内置模型后可删除 ConvNeXt；
3. 下载中取消并继续，确认续传成功且校验失败的文件不会进入正式目录；
4. 在画廊任意作品的大图中打开“雷达画像”，点击“立即生成”，结果即时出现且重开仍存在；
5. 在“六维评价”下载并启用 Qwen，分别运行“标准六维”和“AI 自选六维”，确认来源显示本地模型；停用后内存/显存释放；
6. 断网、移走模型或让新模型启动失败，确认不把画廊图片遮罩，也不把模型故障写成作品拦截。

## 维护规则

1. 同一时间只允许一个任务处于代码施工状态。
2. 来源草案负责表达想法，执行版负责工程边界；冲突时以经过评审的执行版为准。
3. 每阶段必须执行 `npm.cmd run verify`，单独提交并等待验收。
4. 已完成任务移入 `docs/plans/archive/`，不删除 Git 历史和验收证据。
5. 未解决问题进入 `docs/known-issues/` 或带状态的审计账本，不从计划中静默消失。
6. 新能力不得破坏主动下载可信、显式模型分析、Renderer 无任意文件路径和远程 Pixiv 隔离等既有边界。
