## 第一批：找图、继续阅读、保存创作结果

1. 全部作品增加全部、喜欢、最近浏览、未分相册四个常用筛选；与标题搜索、类型、画师和相册条件组合，计数、排序、分页一致。最近浏览暂时按浏览时间排序，离开时恢复之前的排序。
2. 在两个大图入口成功加载原图后记录阅读位置，最多保存最近 100 件作品的位置。点击作品封面继续上次阅读；显式点某一页从该页开始。记录不保存任意路径，不参与偏好学习或 AI 分析，删除作品清理位置。
3. 创作稳定回答和会话可复制、导出 Markdown。主进程根据合法会话/消息 ID 重新读取内容、调用原生保存对话框；显示真实来源，旧记录不补造模型信息，处理中不包含未完成回答。
4. 修复慢创作请求与切换、删除、新建会话的状态竞争；失败重新生成保留原回答。完善分页重叠时的游标，避免重复页导致加载卡住。
5. 常用筛选可通过 Ctrl+K 直达；全局操作的失败提示在创作页也能看到。
6. 图库切页时同步记录滚动位置，避免末次滚动事件尚未送达而丢失位置；探索过期显示响应直接忽略，不能隐藏新显示的视图。
7. 创作小窗口优先保留对话和输入区域，长消息只在消息容器内滚动，不把主页面推走。
