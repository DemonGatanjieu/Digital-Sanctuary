# Pixiv 多图作品「视口焦点」与「单页精准透视/拦截」核心设计逻辑

> 💡 **写在前面（给开发者与用户阅读）**：
> 本文用大白话讲清楚一件事：**当 Pixiv 上一个作品包含好几张图片（多图/漫画/图集）时，AI 怎么识别、怎么透视、怎么精准只拦截其中某几张，以及屏幕上同时出现多张图时怎么确定焦点。**

---

## 一、为什么要有这个设计？（解决什么痛点）

在 Pixiv 上，很多画作是**多图作品**（一个 ID 下有 2 张、4 张甚至几十张图）。
以前的做法容易遇到两个尴尬问题：
1. **特征混在一起**：第 1 页是正常美少女，第 2 页是草图，第 3 页带有某些特殊元素。如果整个作品共用一套标签，就会导致“只要一张违规，整套画作全被拦住”。
2. **不知道当前在看哪张**：用户往下滚动看漫画时，点击「AI 元素透视」，如果系统只展示第一张的标签，用户会一头雾水：“我明明在看第二张，怎么标签显示的是第一张的服装？”

因此，我们必须做到：**单页独立审查、单页独立透视、单页独立拦截与放行**。

---

## 二、核心机制：视口中心几何重心智能吸附（怎么锁定当前看哪张？）

### 1. 原理（找离屏幕正中间最近的那张图）
当用户滚动浏览长图或漫画时，屏幕上可能同时出现好几张图片（特别是在用户缩小了窗口或者图片比较小的时候）。

系统采用 **「视口垂直中心重心吸附（Viewport Center Proximity）」** 算法：
1. 获取当前页面中属于该作品的所有图片位置；
2. 计算每张图片的垂直中心点距离浏览器窗口正中心的垂直距离；
3. **距离屏幕正中间最近的那张图片，就是当前用户的“视觉焦点”**，系统自动将其标记为当前活动页（例如 `P2`）。

---

## 三、直白的用户界面反馈（防止用户困惑）

为了让用户完全明白系统当前在做什么，避免用户因为缩小窗口看到多张图而困惑，系统在界面上直白地告知用户：

1. **抽屉顶部常驻大白话提示条**：
   - 如果是多图作品，透视抽屉顶部会明确显示：
     `💡 已自动匹配视口焦点单页 (P2) · 多图作品可在上方切换查看其他单页`
2. **多图分页药丸选择器（随时手动选）**：
   - 抽屉顶部展示 `[ P1 (主图) ]  [ P2 ]  [ P3 ]  [ P4 ]` 标签胶囊；
   - 无论自动吸附到了哪一页，用户都可以随时手动点击切换到任意想看的某一页。
3. **悬浮按钮动态 Tooltip**：
   - 网页右下角的「🔍 AI 元素透视」胶囊，鼠标悬停时会动态提示：`透视当前视口焦点单页 (P2)`。

---

## 四、单页精准拦截（违规页独立遮挡，安全页正常看）

1. **单页级独立审查**：
   - 视觉大模型在后台对 `_p0`、`_p1`、`_p2` 各自独立打标并独立判断黑名单规则。
2. **互不干扰的独立遮挡**：
   - 如果 P1 是安全的，正常清晰展示；
   - 如果 P2 命中了自定义黑名单（如某些特定特征），只有 P2 会被遮挡并显示 `🛡️ 已拦截` 悬浮卡片；
   - 用户在 P2 上点击「查看」，也只临时放行 P2 这一张图片，整套流程边界清晰、互不干扰。
