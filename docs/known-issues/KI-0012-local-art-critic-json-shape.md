# KI-0012：Gemma 本地画评返回“无法解析为 JSON”

- 状态：已修复
- 发现日期：2026-08-30
- 影响范围：画廊大图 → 多维视觉画像 → Gemma 4 E2B 本地六维

## 表现

模型健康状态正常，但运行标准六维或 AI 自选六维时显示“本地评论模型返回的内容无法解析为 JSON”。该提示无法区分图片拒答、输出截断和结构包装漂移。

## 根因

旧请求只发送 `response_format: { type: "json_object" }`，没有把字段结构交给 llama.cpp 约束。旧解析器也只接受直接 JSON 对象或一段首尾花括号，无法兼容 JSON 字符串、结果包装层、顶层维度数组、普通说明前后缀和尾逗号。

## 修复

1. 固定套件和自选套件分别生成 JSON Schema，约束画面阅读字段以及恰好六项维度；
2. 请求关闭可选思考输出，减少正文外包装；
3. 解析器保守恢复常见包装与尾逗号，恢复后继续执行原有数量、键名、分数和具体证据门禁；
4. 输出达到长度上限、普通拒答和其他格式异常显示不同提示，失败结果不写入缓存；
5. 连续失败后的独立切换模型引导暂记未来体验项，本次不增加新按钮。

## 实机证据

使用用户报告时的同一张本地画廊原图、已安装 Gemma 4 E2B Q4 与 llama.cpp b10516 Vulkan 运行时复现。加入 JSON Schema 后服务返回 HTTP 200、`finish_reason: stop`，并给出可解析的客观画面描述和六个维度；因此该案例不是图片加载失败，也不是模型拒答。
