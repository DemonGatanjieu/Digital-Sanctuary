# KI-0001：WD Tagger 冷启动超时导致首张图片模糊

- 状态：已修复 / 待新安装包实机验收
- 首次记录：2026-08-10
- 影响范围：应用刚启动后立即导入的第一张图片

## 现象

图片没有命中任何元素黑名单，但画廊显示为“已模糊”。

## 已确认原因

桌面端当前对一次视觉请求使用 5 秒超时。WD SwinV2 Tagger v3 的 ONNX 权重约 467 MB，CPU 冷启动时模型初始化与首次推理可能超过 5 秒。请求超时后，领域规则按“视觉服务错误”返回 `blur`，且没有命中理由。

实际记录：

```text
error: Vision request timed out
action: blur
reasons: []
```

这不是黑名单误判，也不代表图片命中了猎奇、血腥、断肢或小便标签。

## 已实施修复（2026-08-23）

- 视觉进程新增 `health-check` 握手，WD Tagger 完成模型和标签表装载后才报告 ready。
- 应用再用内置 1×1 PNG 做一次真实启动推理；握手或推理失败都进入独立故障态。
- 画廊不再依据 `allow / blur / hide` 决策改变本地图片显示；导入图片直接作为可信本地资产。
- 探索在模型启动中或故障时显示一张总状态页，不把失败伪装成每张图片命中规则。

## 待验收

重新构建安装包后，分别验证正常模型、缺失模型与损坏模型三种启动路径。
