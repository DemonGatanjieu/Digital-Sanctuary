# KI-0011：AI 自选六维结果被格式门禁全部拒绝

- 状态：已修复 / 待本地模型目视验收
- 影响范围：画廊大图查看器 → 多维视觉画像 → AI 自选六维

## 现象

图片和本地技术画像均正常，但 AI 自选六维显示英文格式错误。错误会列出模型生成的中文维度名，并在最后报告实际收到 0 项。

## 根因

本地轻量视觉语言模型已经完成看图和评分，却可能不完全遵守内部 JSON 契约：

- 把面向用户的中文维度名同时写入只允许英文标识的 `key`；
- 使用 `explanation` 代替自选套件约定的 `reason`；
- 偶尔返回七项，而不是提示要求的恰好六项。

旧适配层会逐项拒绝中文 key，导致有意义的整次分析被丢弃。这不是图片损坏、视觉投影文件缺失或模型未挂载。

## 修复

- 提示词明确要求六项 key 固定使用 `axis_1` 至 `axis_6`。
- 适配层对中文、空白或重复 key 生成仅供内部使用的安全标识，保留中文 label。
- `explanation` 可作为 `reason` 的兼容别名。
- 模型多返回维度时按分数选择最高六项；少于六项时仍拒绝，不虚构模型结论。
- 修复只容忍传输形状偏差；标签唯一性、分数范围、具体画面依据和非全零规则继续严格检查。
- 界面不再直接展示内部英文校验串，无法安全修复时给出简短中文重试提示。

## 验收

1. 完全退出旧进程并重新启动当前构建。
2. 打开一张本地画廊作品，进入“多维视觉画像”。
3. 点击“AI 自选六维”。
4. 雷达应展示六个中文维度；不应出现 `Highlight key must...` 或 `got 0`。
5. 重复分析其他画风作品，维度名可以变化，但每次必须保持六项。
