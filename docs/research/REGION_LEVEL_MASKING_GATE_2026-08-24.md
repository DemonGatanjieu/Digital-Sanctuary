# 区域级遮罩独立评审门槛（2026-08-24）

- 结论：**当前不进入实现**
- 评审对象：只遮住图片中“不受欢迎元素”的局部区域，而不是遮住整张作品
- 该结论不影响现有整图探索保护，也不影响本地画廊可信显示

## 为什么现在不能假装已经能做

当前 WD SwinV2 Tagger 只返回“整张图包含哪些标签以及置信度”，没有矩形框、像素掩码或区域坐标。把 `blood: 0.78` 直接画成某个局部遮罩没有数学依据，也会制造一种错误的精确感。

仓库当前也没有目标检测或分割模型、区域标注测试集、额外显存基准与局部误遮罩验收夹具。因此 P4 的四道门均未通过：

| 门槛 | 当前证据 | 结果 |
|---|---|---|
| 区域定位准确率 | 无检测/分割输出，无人工标注基准集 | 未通过 |
| 误遮罩风险 | 无局部 Precision / IoU 数据 | 未通过 |
| RTX 4050 显存预算 | 只有 WD Tagger 整图分类基准，没有第二模型并行峰值 | 未通过 |
| 滚动体感延迟 | 没有“下载 → 检测 → 掩码绘制”的 P50/P95 | 未通过 |

## 将来重新开门的最低条件

1. 使用不提交到 Git 的本地私有评测集，覆盖普通图、相似色块、复杂多人构图与真实不受欢迎元素；
2. 候选模型必须真实输出检测框或分割掩码，不能从整图标签猜坐标；
3. 区域 Precision 至少 0.92、Recall 至少 0.85；分割任务另需报告 IoU，且普通图误遮罩率低于 2%；
4. 在目标 RTX 4050 上，与 WD Tagger 共存时额外峰值显存不超过 2.5 GiB；
5. 可见图片单张区域推理 P95 不超过 400 ms，滚动时仍使用视口懒加载与至多 1 路区域推理；
6. 模型未装载、超时或结果置信度不足时，退回当前整图保护状态，绝不伪造区域；
7. 用户能够一键查看原图、撤销反馈，并明确看到“整图标签判断”与“局部模型定位”来自两个不同模型。

## 推荐的下一次研究顺序

1. 先建立离线评测协议和 200～500 张本地夹具；
2. 再比较候选检测/分割模型的许可、体积、Precision/Recall/IoU、显存和 P95；
3. 只做独立实验进程，不接入生产探索；
4. 通过门槛后再写新的实施任务书与安全回退设计。

在以上条件满足前，区域遮罩保持“研究未过门”，这是准确性与用户信任上的完成结论，不是遗漏的代码待办。
