# Renderer 样式维护约定

`../styles.css` 是按顺序列出本目录样式模块的清单。Vite 配置会在内存中把这些模块拼成单一虚拟 CSS 入口，以保留原有单文件级联和滚动性能；不要从渲染代码直接逐个导入模块。这个顺序就是现有级联顺序，除非完成视觉与万级性能回归，否则不要随意调整。

- `tokens.css`、`base.css`：设计变量和全局基础规则。
- `shell.css`、`main-content.css`：应用框架与主内容布局。
- 功能模块：组件、画廊、作者、分类组合、探索、设置和分析等页面样式。
- `responsive.css`：历史响应式覆盖；新增组件优先在所属模块内写响应式规则。
- `saved-views.css`：分类组合功能后加入的模块，暂时保留在原级联位置。
- `interaction-motion.css`：最后加载的有限控件反馈与系统/应用减少动画策略，覆盖 body portal；缩短画册动画但保留结束事件。

新增样式时应放入职责最接近的模块，选择器使用组件或页面前缀，避免把完整页面样式重新堆回 `styles.css`。如果新增 `.css` 文件，必须同时在 `styles.css` 中显式导入；测试会检查遗漏、重复导入和嵌套 `@import`。
